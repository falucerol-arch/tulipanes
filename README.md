# Un jardín para ti 🌷

Regalo digital romántico construido con React, Vite, Framer Motion y CSS.

## Ejecutar en local

```bash
npm install
npm run dev
```

Para generar una versión de producción:

```bash
npm run build
npm run preview
```

El sitio está preparado para publicarse en Vercel o Netlify. La música se genera localmente con Web Audio y solo se activa cuando la visitante pulsa el control.
